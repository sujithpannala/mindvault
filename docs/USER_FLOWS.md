# MindVault – User Flows

## 1. Create a New Note

**Goal:** Capture a thought as quickly as possible.

1. User opens MindVault
2. Clicks "New Note" (or uses keyboard shortcut)
3. Types a title
4. Writes content in Markdown
5. Optionally adds tags
6. Optionally assigns a collection
7. Saves (auto-save preferred)
8. Returns to notes list or stays in editor

**Success:** Note is saved and appears in the list immediately.

---

## 2. Find an Existing Note

1. User focuses the search input (or presses Cmd/Ctrl + K)
2. Types keywords
3. Results update live
4. User clicks a result
5. Note opens in the editor

**Success:** Relevant note is found in seconds.

---

## 3. Organize Notes

1. User opens a note
2. Adds or removes tags
3. Moves note to a different collection
4. Changes are saved automatically

**Success:** Note is correctly categorized and filterable.

---

## 4. Review & Reflect

1. User browses a collection or tag
2. Opens several notes
3. Edits or expands ideas
4. Pins important notes (future)

**Success:** User can revisit and improve existing knowledge easily.
